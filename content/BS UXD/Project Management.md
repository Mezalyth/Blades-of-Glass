The six project management concepts shown in the chart are 
- project selection criteria
- project lifecycle
- project management methods
- project planning
- project scheduling, executing, monitoring and controlling 
- closing project work.

#### Triple Constraint
- COST/BUDGET
- TIME/SCHEDULE
- SCOPE

Any change in one of these will affect the other two.
